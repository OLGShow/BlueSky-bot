## 🛠️ Установка на сервер:

### 1. Остановить старого бота:
```bash
sudo systemctl stop bluesky-bot
```

### 2. Скопировать новые файлы:
```bash
# Скопировать основные файлы
scp bluesky_bot_v2.py root@server:/home/bluesky/BlueSky-Bot/
scp ai_improvements.py root@server:/home/bluesky/BlueSky-Bot/
scp bot_config.json root@server:/home/bluesky/BlueSky-Bot/
scp requirements.txt root@server:/home/bluesky/BlueSky-Bot/
```

### 3. Обновить зависимости:
```bash
cd /home/bluesky/BlueSky-Bot/
source venv/bin/activate
pip install -r requirements.txt
```

### 4. Скопировать память с сервера в локальную папку:
```bash
# Уже выполнено - память в serverMemory/bot_memory.pkl
# Скопировать обратно на сервер при необходимости:
scp serverMemory/bot_memory.pkl root@server:/home/bluesky/BlueSky-Bot/
```

### 5. Запустить бота:
```bash
sudo systemctl start bluesky-bot
sudo systemctl status bluesky-bot
```

### 6. Мониторинг:
```bash
# Просмотр логов
sudo journalctl -u bluesky-bot -f

# Проверка статуса
sudo systemctl status bluesky-bot
```

## 🎯 Ключевые метрики для отслеживания:

1. **Engagement Rate** (лайки + репосты + комментарии) / подписчики
2. **Viral Score** - посты с >50 лайков или >10 репостов
3. **Growth Rate** - новые подписчики в день
4. **Content Quality** - средний балл качества постов
5. **Peak Performance** - активность в пиковые часы

## 🔧 Настройка и оптимизация:

### В `bot_config.json` можно настроить:
- `viral_content_settings.min_viral_score` - минимальный балл для вирусного контента
- `bluesky_limits.posting_schedule.peak_hours_utc` - пиковые часы для вашей аудитории
- `post_strategies` - процентное соотношение типов контента
- `audience_optimization.target_demographics` - целевая аудитория
